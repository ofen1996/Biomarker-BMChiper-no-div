# Contributing

Thank you for your interest in this project.

## Before opening an issue

- Describe the input format and a minimal reproducible case.
- Do not upload private, clinical, or proprietary image data.
- Include the Python version, operating system, package versions, and relevant configuration preset.

## Pull requests

- Keep changes focused and document any configuration changes.
- Do not commit datasets, credentials, machine-specific paths, or large generated image outputs.
- For image-processing changes, include a small reproducible example or explain how the result was checked.

## Scope

This repository is a portfolio implementation for specialised imaging workflows. Compatibility and output quality should be validated for each acquisition setup before production use.
